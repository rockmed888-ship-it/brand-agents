Brain Connector

Install the brain. Plug it into the work.

This install is only Brain Connector. It does not install Brand Agents or Booked Out. After it is on the computer, open a terminal and type brain. Then build a connector for a website, an assistant, or an automation.

Download the Brain Connector install

Tiers

Hobby $20 for 1,000 calls. Learner $30 for 3,000. Brilliant $40 for 10,000. The brain uses only the notes you attach. It does not send, post, or pay by itself.

irm https://brandbyagents.com/downloads/brain-install.ps1 | iex

Then, in a new terminal:

brain build --kind website --tier hobby --name "Your shop" --source "What the brain is allowed to know."

Use --kind assistant or --kind automation and --actions "book,quote" when it is allowed to act. The command writes an MCP file tailored to that request.
