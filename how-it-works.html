    Reload the app. The pet shows. They click. You stay on Send.

Phone (Android)

Open Get in Chrome on the phone. Patch file is DD.apk — the app is named DD. BeeDee file is BeeDee.apk — the app is named BeeDee.

Patch

  1. Download Patch. Allow Install unknown apps for Chrome if asked.
  2. Open the app named DD.
  3. Tap Overlay.
  4. Tap Hands. Accessibility → turn on DD.
  5. Tap Start DD.
Patch steps

BeeDee

  1. Download BeeDee. Allow Install unknown apps for Chrome if asked.
  2. Open the app named BeeDee.
  3. Tap Overlay.
  4. Tap Hands. Accessibility → turn on BeeDee.
  5. Tap Start BeeDee.
BeeDee steps

Windows

Download Brand Agents for Windows. Launch Brand Agents from the Start menu. In the app: choose Patch, BeeDee, or describe anyone → Save → paste the Server URL → copy the same line into Grok as Brand Agents → reload if Grok built a custom pet.

What you keep
