Install BeeDee on this phone

The download is free. You do not pay to install. On the phone the app is named BeeDee. Open this page in Chrome on the phone.

Install (free)

  1. Tap Download BeeDee. The file is BeeDee.apk.
  2. If Chrome blocks it: open the download → Settings → allow Install unknown apps for Chrome → install.
  3. Open BeeDee.
  4. Tap Overlay → allow display over other apps.
  5. Tap Hands → Accessibility → installed apps → turn on BeeDee.
  6. Tap Start BeeDee. Leave the notification on.
