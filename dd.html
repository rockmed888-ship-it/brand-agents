Install DD on this phone

Open this page on the phone. After Start DD, the Grok app on this phone runs these hands. Hold the pet to talk. Double-tap to stop. Overlay is Patch.

3 taps

  1. Download and install DD.apk. Allow Chrome to install this app — Play does not allow this kind of helper yet.
  2. Allow Overlay (Patch sits on screen so you can see when DD is working — not ads). Settings → Accessibility → DD → on.
  3. Open DD → allow “run in background” if asked → Start DD. Leave the notification on.
