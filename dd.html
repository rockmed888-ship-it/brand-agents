Install Patch on this phone

The download is free. You do not pay to install. Overlay is Patch. On the phone the app is named DD. Open this page in Chrome on the phone.

Install (free)

  1. Tap Download Patch. The file is DD.apk.
  2. If Chrome blocks it: open the download → Settings → allow Install unknown apps for Chrome → install.
  3. Open the app named DD (that is Patch).
  4. Tap Overlay → allow display over other apps.
  5. Tap Hands → Accessibility → installed apps → turn on DD. It is not listed as Patch.
  6. Tap Start DD. Leave the notification on.
