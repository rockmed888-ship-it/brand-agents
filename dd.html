Install Patch on this phone

Open this page on the phone. After Start, the Grok app on this phone clicks here. Hold the pet to talk. Double-tap to stop. Overlay is Patch.

3 taps

  1. Download and install Patch. Allow Chrome to install this app — Play does not allow this kind of helper yet.
  2. Allow Overlay (Patch sits on screen so you can see when they are working — not ads). Settings → Accessibility → Patch → on.
  3. Open Patch → allow “run in background” if asked → Start. Leave the notification on.
