Phone install (free)

You do not pay for the APK. The trial is only the Grok Server URL.

  1. Open this page in Chrome on the phone.
  2. Download Patch (DD.apk) or BeeDee (BeeDee.apk).
  3. If Chrome blocks it: allow Install unknown apps for Chrome, then install.
  4. Open DD (Patch) or BeeDee.
  5. Tap Overlay.
  6. Tap Hands.
  7. In Accessibility turn on DD or BeeDee — not the word Patch.
  8. Tap Start DD or Start BeeDee.
  9. In the app: choose boy, girl, or describe anyone → Save.
  10. Paste the Server URL → Save. Then Grok → Connectors → Custom → name Brand Agents.
  11. If Grok built a custom pet, reload Brand Agents. The pet shows.

Patch steps · BeeDee steps

Windows install

  1. Download Brand Agents for Windows.
  2. Double-click the installer and follow the wizard.
  3. Launch Brand Agents from the Start menu or desktop. Leave it running.
  4. In the app: choose Patch, BeeDee, or describe anyone. Save.
  5. Paste the Server URL from trial. Save.
  6. Copy that connector. Paste in Grok as Brand Agents.
  7. If you described someone, Grok builds them. Reload Brand Agents. The pet shows.
  8. If Windows SmartScreen appears: More info → Run anyway.

No npm install. No developer tools. Node.js is not required.
