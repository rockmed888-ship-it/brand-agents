Download BeeDee for Android Install steps

Windows install

  1. Download Brand Agents for Windows.
  2. Double-click the installer and follow the wizard.
  3. Launch Brand Agents from the Start Menu or desktop. Leave it running.
  4. Console to Start. Save info. Save memories. Drop CHOSEN-AGENT.json in the app console / office/files if you named a pet.
  5. If Windows SmartScreen appears: More info → Run anyway. Publisher should say Brand Agents when we are signed.

No npm install. No developer tools. Node.js is not required.

Managed cloud account

After install, open Settings → Managed Brand Agents to register/login and checkout. BYOK keys never leave your PC.
