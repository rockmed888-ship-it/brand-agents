## Lead positioning (homepage)

**Primary:** A trainable desktop agent that works on your computer under your control.

**Secondary analogy only:** Jarvis-like — further down the page.

### Four homepage pillars

1. Lives on your desktop  
2. Learns how you work  
3. Acts only with the permissions you choose  
4. Gets more capable as you build trust  

### Biggest differentiator

**The agent has memory of how you work.**  
Not “it uses GPT / Claude / Grok.”
