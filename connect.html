In the app, then Grok

  1. Choose boy (Patch), girl (BeeDee), or describe anyone. Save.
  2. Paste the Server URL in the app. Save.
  3. Open grok.com/connectors.
  4. New Connector → Custom. Name it Brand Agents.
  5. Paste the same Server URL. No Bearer field. If the URL is only /mcp without /p/…, it will not attach.
  6. If you described someone, Grok builds that 3D toy. Reload Brand Agents. The pet shows.
